 스팀 게임 Database Detective(HsuCorp)의 비공식 한글패치입니다.
 화면 문구와 대사는 물론, 사진 단서와 사용 설명서 23쪽까지 한글로
 다시 그려 넣었습니다.

 게임 원본 파일은 하나도 고치지 않습니다.
 파일을 더 넣어 게임이 켜질 때 한글을 얹는 방식입니다.


--------------------------------------------------------------------
 설치
--------------------------------------------------------------------

 1. 스팀 라이브러리에서 Database Detective를 오른쪽 클릭하고
    [관리] - [로컬 파일 보기]를 고릅니다.

 2. 이 압축 파일 안의 것을 그 폴더에 **전부 풀어 넣습니다.**
    덮어쓸지 물으면 덮어씁니다.

 3. 게임을 켭니다. 처음 한 번은 검은 창이 잠깐 더 떠 있습니다.

 제대로 들어갔다면 게임 폴더가 이렇게 됩니다.

    Database Detective\
      copOS.exe
      winhttp.dll            <- 새로 들어간 것
      doorstop_config.ini    <- 새로 들어간 것
      .doorstop_version      <- 새로 들어간 것
      changelog.txt          <- 새로 들어간 것
      BepInEx\               <- 새로 들어간 것
      copOS_Data\
      ...

--------------------------------------------------------------------
 지우기
--------------------------------------------------------------------

 게임 폴더에서 아래만 지우면 원래대로 돌아갑니다.

    winhttp.dll
    doorstop_config.ini
    .doorstop_version
    changelog.txt
    BepInEx  폴더

 게임 원본 파일은 건드리지 않았으므로 이것으로 끝입니다.


--------------------------------------------------------------------
 설정 바꾸기
--------------------------------------------------------------------

 게임을 한 번 켜면 아래에 설정 파일이 생깁니다.

    BepInEx\config\kr.spade.databasedetective.koreanpatch.cfg

 자주 손대는 것만 적습니다. 나머지는 파일 안에 설명이 붙어 있습니다.

    FontFile = neodgm.ttf
        글꼴. 동봉한 Neo둥근모입니다. 비워 두면 FontFamily에 적힌
        윈도우 글꼴(기본 맑은 고딕)을 씁니다.
        fonts 폴더에 ttf를 넣고 이름을 적으면 그것을 씁니다.

    EnterBehavior = Newline
        쿼리창에서 Enter를 누르면 줄이 바뀝니다. 쿼리 실행은 Ctrl+Enter.
        Submit으로 바꾸면 Enter가 실행, Shift+Enter가 줄바꿈이 됩니다.

    EnableTypingSound = true
        글자를 칠 때 나는 타건음. 끄려면 false.

    EnableTranslation = false
        번역을 통째로 끄고 원문으로 돌립니다.
        (입력 버그 수정과 타건음은 그대로 남습니다)

 사진 단서와 사용 설명서는 창 안의 버튼으로 원본 그림과 번갈아 볼 수
 있습니다. 원문이 궁금할 때 눌러 보십시오.


--------------------------------------------------------------------
 잘 안 될 때
--------------------------------------------------------------------

 ● 게임은 켜지는데 그대로 영어입니다

    게임을 한 번 켠 뒤 BepInEx\LogOutput.log 를 열어 보십시오.

       [Info : Database Detective Korean Patch] 로드 완료. 메서드 18개 패치.

    이 줄이 있으면 패치는 들어가 있습니다. 없다면 파일을 게임 폴더가
    아닌 다른 곳에 푼 것입니다. copOS.exe 가 있는 폴더가 맞습니다.

 ● 글자가 네모(□)로 보입니다

    설정에서 EnableKoreanFont 가 true 인지 보십시오.
    FontFile 에 적은 글꼴 파일이 fonts 폴더에 없어도 이렇게 됩니다.

 ● 스팀에서 파일 무결성 검사를 돌렸더니 패치가 풀렸습니다

    검사를 돌리면 게임에 없던 파일이 지워질 수 있습니다.
    이 압축 파일을 다시 풀어 넣으면 됩니다.

 ● 그 밖의 문제

    BepInEx\LogOutput.log 를 아래 주소에 올려 주시면 보겠습니다.
    https://github.com/krPlatypus/Database-Detective-Korean-Patch/issues
